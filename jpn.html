日本酒ログ記録・AIラベル読み取り・テイスティングカード共有・味覚分析・産地コレクションの全機能詳細ガイド

1. SakeRecord アプリ概要

SakeRecord（サケレコード）は、飲んだ日本酒のスペック・写真・味わいをスマートに記録し、AIによるラベル文字読み取りアシストや、SNSでシェアできるテイスティングカード生成、インタラクティブな味のポジショニングマップ＆好み診断、47都道府県制覇コレクションとして管理できるiOS専用の日本酒管理アプリケーションです。

3. タブ1：ログ（日本酒記録リスト）

3.1 メイン画面と検索・フィルタリング

リスト表示・「飲んだログ / 飲みたいリスト」切替・登録件数表示

登録された日本酒ログが飲んだ日付の新しい順（降順）で一覧表示されます。リスト最上部のヘッダーにはモード切替ピルと現在のデータ件数がリアルタイムに表示されます。

  • 「🍶 飲んだログ」と「🔖 飲みたい (PRO)」のワンタップ切替：リスト上部のボタンで、実際に飲んだお酒の記録と、これから飲みたい「気になるお酒メモ（ウィッシュリスト）」を瞬時に切り替えられます（※プロプラン限定）。飲みたいリストの行を右スワイプして「🍶 飲んだ！」をタップすると、今日の日付で通常ログへ一発昇格できます。
  • 登録件数・検索ヒット件数の表示：通常時はリスト上部に「登録件数: 〇件」を表示し、検索キーワード入力中は「検索結果: 〇件 / 全〇件」を自動集計して表示します。
  • 銘柄名：左側に配置（長すぎる場合は1行で省略表示）。
  • 飲んだ日：右側にグレーの小文字で表示。
  • 評価の星（★）：日付の右隣にオレンジ色（★1〜★5）で表示（未評価の場合は非表示）。
  • スワイプ削除：リスト行を左にスワイプすることで該当ログを削除できます。

高度な検索バー（Searchable）

画面上部の検索バーを利用して、記録済みの全データを即座に絞り込むことができます。

  • キーワード検索：銘柄名、特定名称、酒米、酵母、醸造所（蔵元）、都道府県、自由コメントに含まれる文字列をあいまい検索します。
  • 評価（星数）ダイレクト検索：検索バーに「1」〜「5」の半角数字を1文字だけ入力すると、その評価星数（★1〜★5）に一致するログのみを瞬時に抽出します。

3.2 ツールバーの各種操作ボタン

  • 産地コレクションボタン（🏅メダルアイコン）：ナビゲーション左側に配置。タップすると「都道府県制覇画面」へ遷移します。
  • 味の分析マップボタン（📈グラフアイコン）：ナビゲーション左側に配置。スタンダード・プロプラン限定。タップすると「味のポジショニングマップ＆好み診断」へ遷移します。無料版では非活性表示（グレーアウト）となります。
  • サブメニューボタン（「...」アイコン）：
    • データを書き出す（square.and.arrow.up）：スタンダード・プロプラン限定。全ログと画像をフォルダ形式で共有シートに書き出します。
    • データを読み込む（square.and.arrow.down）：バックアップフォルダを選択し、データベースへ一括インポートします。
  • 新規登録ボタン（「＋」アイコン）：ナビゲーション右側に配置。タップすると「新規登録シート（SakeInputView）」が下部から立ち上がります。

3.3 新規登録画面（SakeInputView）の全入力項目とAIラベル読み取り

新規に日本酒ログを登録する画面です。以下の入力項目で構成されています。

1. ラベル・その他の写真セクション ＆ AIラベル読み取り（Pro限定）

  • 横スクロール写真タイル：左から「表ラベル」「裏ラベル」「サブ1」「サブ2」「サブ3」の最大5枠が並びます。
  • タイルタップ操作：未登録時はカメラが自動起動します。登録済み時は拡大プレビューギャラリーが開きます。無料版で「サブ1〜3」をタップした場合はアップグレード案内アラートが表示されます。
  • 「アルバムから登録」ボタン：ライブラリから複数写真（無料版:最大2枚、スタンダード/プロ版:最大5枚）を一括選択して順に割り当てます。既に写真が登録されているスロットに割り当たる場合は「写真の上書き確認」アラートがポップアップ表示され、既存写真の不意な消失を防ぎます。
  • ✨ AIラベル読み取り（自動抽出＆ワンタップ反映）※プロ (Expert) 限定：
    • 写真を撮影・選択すると自動的に（または「AIラベル読み取り」ボタンをタップして）ラベル内の文字解析が実行されます（過去に登録済みの写真に対しても詳細画面からいつでも実行可能です）。
    • 縦書き・漢数字対応の3段階ハイブリッド解析：iOSのLive Text（VisionKit）＋1文字ずつの座標から縦書き列を復元する独自アルゴリズムに加え、アプリ内のスキャン辞書（SakeDictionary）照合、オンデバイスAI（iOS 26 FoundationModels）、およびGemini Vision API（設定時）を組み合わせて解析します。縦書き裏ラベルの漢数字（精米歩合 五十％、四割五分、アルコール分 十六度など）も自動で数値に変換します。
    • 候補チップのワンタップ反映：勝手に既存入力を上書きせず、[特定名称: 純米吟醸酒] [酒米: 山田錦] [精米歩合: 50%] [度数: 16%] のような紫色の候補チップとして表示します。各チップをタップして個別に反映するか、「すべて反映」ボタンで一括入力できます。
    • 「読み取った文字一覧から選ぶ」機能：辞書に未登録の新しい銘柄や文字列も、展開リストからタップして「銘柄名にセット」「醸造所にセット」「自由コメントに追記」などを2タップで選べます。

2. 自由コメントセクション

写真セクションの直下に配置された長文用テキストエディタです。テイスティングメモ、購入店、価格、ペアリングした料理などを自由に入力できます。

3. 総合評価セクション

1〜5段階の星（★）をタップして評価を設定します。

4. 基本情報セクション

  • 銘柄名（必須）：お酒の銘柄を入力。
  • 特定名称（Picker）：設定なし / 普通酒 / 純米酒 / 特別純米酒 / 純米吟醸酒 / 純米大吟醸酒 / 本醸造酒 / 特別本醸造酒 / 吟醸酒 / 大吟醸酒 / その他 から選択。
  • 製法：生酛、山廃仕込、無濾過生原酒、袋吊り、中取り、あらばしり、火入れ、生酒、原酒、にごり酒、生詰、生貯蔵、古酒、スパークリングなど。
  • 酒米：山田錦、五百万石、美山錦、雄町、出羽燦々、愛山など。
  • 精米歩合（%）：数値キーボードで入力（例: 50）。
  • 度数（%）：アルコール度数を数値キーボードで入力（例: 15）。
  • 酵母：協会6号、7号、9号、1801号、静岡酵母、蔵付き酵母など。
  • 醸造所：蔵元名・酒造会社名を入力。
  • 都道府県：全国47都道府県＋その他から指定。
  • 飲んだ日：カレンダー（DatePicker）から選択。

5. リアルタイム予測変換・サジェストバー（キーボードツールバー）

銘柄名、製法、酒米、酵母、醸造所、都道府県の入力時、キーボード上部にサジェスト候補が横スクロールで自動表示されます。候補ボタンをタップすると入力が完了し、辞書内の使用カウントが自動加算されます。

6. 味の分析セクション

  • 味の4軸ピッカー（セグメント制御）：
    • 濃淡：淡麗(1) / 中庸(2) / 濃醇(3)
    • 甘辛：甘口(1) / 中庸(2) / 辛口(3)
    • 香り：穏やか(1) / 普通(2) / 華やか(3)
    • 性質：熟成(1) / 普通(2) / ﾌﾚｯｼｭ(3)
  • 特徴フラグ（チェックボックス）：発泡 / コメうま / コク / 苦味 / キレ

7. 記録タイプ切替（飲みたいリスト） ＆ 飲み方・ペアリング記録（Pro限定）

  • 記録タイプ（🍶 飲んだ ／ 🔖 飲みたい [PRO]）：プロプランでは「🔖 飲みたい」を選択して保存することで、銘柄名が未入力でもラベルやメニューの写真だけで素早く仮登録できます（統計や都道府県制覇数には混ざらず、実際に飲んだときにワンタップで通常ログへ昇格できます）。
  • おすすめの温度帯（複数選択可 [PRO]）：❄️ 雪冷え・花冷え(5〜10℃)、💧 涼冷え(15℃前後)、🍶 常温(冷や)、♨️ ぬる燗(40℃前後)、🔥 熱燗(50℃〜)、🧊 ロック・ソーダ割 から複数タップ選択できます。
  • 相性の良かった料理・おつまみ（複数選択可 [PRO]）：🐟 刺身・寿司、🐚 焼き魚・海鮮、🥩 肉料理、🍢 鍋・おでん、🧀 チーズ・洋食、🦑 珍味・塩辛、🍤 天ぷら・揚げ物、🥂 単体・乾杯向き から複数選択でき、テイスティングカード画像にも自動で表示されます。

3.4 詳細・編集画面（SakeDetailView）、テイスティングカード共有、写真拡大表示（SakeImageDetailView）

登録済みログの全項目の確認・修正、AIラベル再スキャン、およびカード画像共有が可能です。

  • 🍶 テイスティングカードを作成・シェア（SakeTastingCardSheetView）： 写真セクション下部のオレンジ色の「テイスティングカードを作成・シェア」ボタン、または画面右上の共有アイコン（square.and.arrow.up）から起動します。
    • 1枚のカード画像に自動合成：ラベル写真、銘柄名、蔵元・都道府県、飲んだ日、★評価、酒米・精米歩合・度数・酵母、味の4軸メーター、特徴タグ（#発泡 #コメうま等）、自由コメントをスタイリッシュなカード画像にまとめます。
    • 3種類の和風カラーテーマ切替：「和モダン（紺）」「白磁（生成り）」「朱漆（茜）」の3テーマをワンタップで切り替えられます。
    • 自由コメント表示のON/OFF：SNS投稿時などに個人的なメモ（自由コメント）をカードに載せるか隠すかをトグルスイッチで即座に切り替えられます。
    • 高画質＆軽量JPEGでのSNSシェア・写真保存：Retinaディスプレイ対応の高解像度（3倍スケール）でありながら、約200〜300KBの軽量なJPEG画像として「SNS・LINEなどでシェアする」または「iPhoneの写真フォルダに保存」を実行できます。
  • 🔄 過去のリピート・同蔵元比較セクション（Pro限定）： 過去に同じ銘柄（別ロットや生原酒・ひやおろし等のスペック違い）や、同じ蔵元の別銘柄を記録している場合、詳細画面の最下部に自動で比較リスト（通算記録回数・平均★評価・過去ログへのダイレクト遷移リンク）が表示されます。
  • 蔵元Google検索ボタン：画面右上の「🔍」アイコンをタップすると、銘柄名と蔵元名をもとにGoogle検索を実行するブラウザが開きます。
  • 写真の拡大表示・入れ替え・ダウンロード保存・削除（SakeImageDetailView）： 写真タイルをタップするとピンチズーム対応のフルスクリーン拡大表示が開きます。
    • 画像の入れ替え（🔄カメラアイコン）：ツールバー左側の入れ替えボタンから、カメラ撮影またはライブラリ選択で写真を更新できます。
    • iPhoneの写真フォルダに保存（📥ダウンロードアイコン）：ツールバー左側のダウンロードボタン（square.and.arrow.down）をタップすると、現在表示しているラベル写真をiPhone本体の「写真」アプリ（カメラロール）へ直接保存できます。
    • 写真の削除（🗑️ゴミ箱アイコン）：ツールバー左側の赤色ゴミ箱ボタンをタップすると確認ダイアログが表示され、現在表示中の写真だけを安全に削除（クリア）できます。

4. タブ2：写真アルバム（SakePhotoGalleryView） ※スタンダード・プロ限定

ビジュアルギャラリーとピンチイン・アウト制御

スタンダードプランおよびプロ (Expert) プランのユーザーに表示される専用タブです。登録されているすべてのラベル写真（表・裏・サブ）が、画面いっぱいのグリッド状に並んで表示されます（※無料版ユーザーにはタブ自体が表示されません）。

  • ヘッダー非表示化：写真にタイトル文字列が被るのを防ぐため、ナビゲーションバーを非表示にした洗練された表示設計となっています。
  • ピンチ操作による列数変更：画面上で2本の指を広げる（ピンチアウト）と拡大（列数が減少：最小2列）、すぼめる（ピンチイン）と縮小（列数が増加：最大5列）へインタラクティブに切り替わります。
  • タップ遷移：写真タイルをタップすると、その写真が属するログの詳細画面（SakeDetailView）へダイレクトに移動します。

5. タブ3（無料版はタブ2）：設定とカスタマイズ

5.1 設定メニュー項目（SettingsView）

  • 現在のプラン表示・切り替え：現在有効なプラン状態（無料版 / スタンダード / プロ (Expert)）の確認および切り替えが行えます。
  • スキャン設定：
    • スキャン辞書の編集（DictionaryEditView）：入力時のサジェストおよびAIラベル読み取りで使用される辞書キーワードの追加・検索・編集・削除・使用回数の管理を行えます。
      • カテゴリ切り替え（銘柄 / 蔵元 / 製法 / 酒米 / 酵母）。
      • 「X回使用」バッジ表示および「初期」データマーク表示。単語をタップまたは左スワイプして名称・よみがなの編集や削除が可能。
      • 「＋」ボタンから新しいキーワードとひらがな読みを追加可能（辞書に登録するほどAIラベル読み取りのヒット精度も向上します）。
      • 辞書データのバックアップ・復元：右上「...」メニューから SakeDictionary_Backup_yyyyMMdd.json 形式でのエクスポート・インポートを実行できます。
    • Gemini APIキー設定（プロプラン限定・任意）：AIラベル読み取りは未設定でもiPhone内蔵のOCR＋オンデバイスAIでオフライン動作しますが、Gemini APIキーを設定すると、達筆な毛筆の表ラベルなどもクラウド画像認識AIで高精度に読み取ることができます。
  • ヘルプ・チュートリアル：
    • ユーザーマニュアル：本Webマニュアルを開きます。
    • 初回チュートリアルを表示：アプリの使い方スライド（SakeTutorialView）を再表示します。
  • アプリについて：現在のアプリバージョンが表示されます。

6. 補助画面・バックアップ仕様

6.1 産地コレクション（PrefectureGridView）

全国47都道府県の制覇状況を可視化します。

  • 制覇プログレスバー：画面上部に「X / 47 都道府県」の進捗メーターを表示（飲みたいリストは除外し、実際に飲んだお酒で集計）。
  • 🗾 日本全国 制覇ヒートマップ ＆ 県別ドリルダウン一覧（Pro限定）：日本列島ブロック白地図が飲んだ本数に応じて段階的にオレンジ〜ゴールドに塗りつぶされます。マップ上の県タイルまたは下部の都道府県メダルをタップすると、「その県で飲んだお酒一覧シート（高評価順／新しい順切替・詳細画面への直接遷移）」が開きます。
  • 都道府県セル：一度でも飲んだことのある都道府県にはオレンジ色のメダル（🏅）と飲んだ本数が表示され、未達成の都道府県はグレー表示となります。

6.2 味のポジショニングマップ＆好み傾向・ランキング診断（SakeTasteMapView） ※スタンダード・プロ限定

過去のお酒の味わいを2次元マップ上にプロットし、さらに自分の好みの傾向や相性の良いスペックを自動診断します。

  • 2種類のマップ軸モード切替：
    • 「甘辛 × 濃淡」マップ：横軸＝甘口↔辛口、縦軸＝淡麗（下）↔濃醇（上）。
    • 「香り × 性質」マップ：横軸＝穏やか↔華やか、縦軸＝熟成（下）↔フレッシュ（上）。
  • 「★4以上の高評価のみ」フィルター：ワンタップで高評価（★4〜5）のお酒だけに絞ってマップ上の分布を確認できます。
  • プロット点のタップで銘柄確認＆詳細遷移：マップ上のオレンジ色の点をタップすると、そのお酒のラベル写真・銘柄名・特定名称・酒米・蔵元・★評価カードがマップ直下にポップアップ表示され、カードをタップするとそのまま詳細画面へ遷移できます。同じ座標エリアに複数のお酒が重なっている場合も、カード上部の切り替えピルからすべてのお酒を選択できます。
  • あなたの好みタイプ診断カード：高評価のお酒の傾向から、「華やかフルーティ × 濃醇甘口・旨口タイプ」などのタイプ診断タイトル・解説文・よく選ぶ特徴タグ（#コメうま #キレ等）を自動生成します。
  • 相性ベスト3ランキング：これまでの記録から「よく飲む・相性の良い酒米 ベスト3」「よく飲む特定名称 ベスト3」「お気に入りの蔵元 ベスト3」を本数と平均★評価付きでランキング表示します。

6.3 データバックアップと復元構造

ログバックアップフォルダ構成 (SakeLog_Backup_yyyyMMdd)

「データを書き出す」を実行すると、日付付きのフォルダが自動生成され、以下のファイルが出力されます。

  • data.json：全レコードのテキストデータ、評価、日付、設定値をISO8601準拠JSON形式で出力。
  • 銘柄名_UUID8桁_front.jpg / _back.jpg / _sub1.jpg 等：各ログに紐付く圧縮JPEG画像ファイル。

「データを読み込む」を実行してこのフォルダを選択することで、既存データと重複することなく安全に一括インポート・復元が行われます。
